Check a GitHub repo for memory-unsafe code

Paste a repository and get a list of the spots worth reviewing before you depend on it: unbounded copies, unchecked buffers, format strings, and unsafe blocks in C, C++, Rust, Go, C#, Zig, and Python's ctypes.

This scanner matches known risky patterns line by line. It doesn't compile or trace the code, so some findings will be safe in context and some real bugs won't show up. Treat it as a reading list for review, not a verdict. Vendored and third_party folders are skipped.
